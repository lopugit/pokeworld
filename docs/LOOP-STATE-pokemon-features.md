## Requested features (user)

1. **Walk animation** — player sprite animates with Emerald walk frames while
   moving (directional: up/down/left/right, step cycle).
2. **User settings** — boy/girl selection + name entry; name appears in NPC
   dialogs and across the game; sprite matches gender (Brendan/May).
3. **Pokédex + wild encounters + battles** — full 386 (Gen I–III) dex; wild
   Pokémon found in long grass, near/in caves, and while surfing on water;
   battle screen with FIGHT / BAG (balls + potions in battle) / POKéMON / RUN;
   catching with Gen III formulas; item use from bag onto team Pokémon; exp +
   level ups; Pokédex seen/caught tracking.
4. **Admin spawn-rule UI** — /admin section listing all Pokémon with editable
   spawn chance / biome / lat-lng geofence rules. Default: everything spawns
   world-wide fenced only by biome (grass types in long grass, water types on
   water, etc.). Legendaries geofence-able (e.g. Groudon within 100 km of
   Uluru). **Variants system**: multiple rules per species, each with its own
   fence, level range, gender override, shiny-odds override.

## Architecture decisions

- Pokédex data: `app/src/data/pokedex.json` generated by
  `app/scripts/fetch-pokedex.mjs` from PokeAPI (id 1–386: name, types, base
  stats, catch rate, gender rate, base exp, growth, legendary flag, genus,
  flavor). Sprites committed under `app/public/sprites/pokemon/gen3/`
  (`{id}.png`, `shiny/{id}.png`, `back/{id}.png`, `back-shiny/{id}.png`) —
  Emerald fronts, Ruby/Sapphire backs, with fallbacks.
- Player sprites: sliced from pret/pokeemerald `brendan|may/walking.png` by
  `app/scripts/fetch-character-sprites.mjs` →
  `app/public/sprites/player/{boy,girl}/{down,up,side}-{0,1,2}.png` (side
  mirrored for right in-canvas).
- Trainer state v4: adds `gender`, `pokedex: {seen, caught}`, party members
  gain `speciesId`, `exp`, `shiny`, `gender`, `stats`, `moves`. v3 migration
  maps legacy species names → dex ids.
- Encounters resolved **client-side** (offline-friendly): defaults computed in
  `src/lib/encounters.ts` from pokedex.json; server stores only admin
  overrides (`spawnRules` Mongo collection; in-memory fallback offline).
  Public `GET /api/spawn-rules`; admin CRUD `GET/PUT/DELETE
  /api/admin/spawn-rules` (requireAdminSession, same pattern as
  generation-quota).
- Biome detection: `long-grass` = tile.feature `long-grass`; `water` = tile
  terrain/img water while surfing; `cave` = walkable tile within 3 tiles of a
  `cave-entrance` feature. Surf: press A facing water with a WATER-type in
  party; dismount stepping onto land.
- Battle: pure reducer in `src/lib/battle.ts` (injectable RNG), Gen III
  damage/catch/exp formulas, type chart, typed generic movepools (real
  per-species learnsets out of scope). UI overlay `BattleScreen.tsx` inside
  `.game-ui-layer`.
